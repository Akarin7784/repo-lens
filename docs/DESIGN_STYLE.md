# 界面设计风格:Claude 风格

产品负责人决定:RepoLens 的界面采用 Claude 的设计风格。本文件是前端实现的视觉基准,与 `FRONTEND_DESIGN.md` 冲突时,视觉部分以本文件为准。

## 设计原则
1. **温暖、克制、阅读优先**:大量留白,信息密度靠层级而不是边框和阴影堆出来。
2. **内容是主角**:图和答案占据视觉中心,控件尽量轻。
3. **圆润而安静**:大圆角、细边框、柔和阴影,不使用高饱和渐变和炫光。

## 设计令牌(Design Tokens)
| 用途 | 浅色 | 深色 |
|---|---|---|
| 页面背景 | `#FAF9F5`(暖米白) | `#262624` |
| 卡片/面板背景 | `#FFFFFF` | `#30302E` |
| 主文字 | `#1F1E1D` | `#F5F4EE` |
| 次要文字 | `#6B6A68` | `#A8A7A2` |
| 边框 | `#E8E6DC` | `#42413E` |
| 强调色(陶土橙) | `#D97757` | `#E08A6A` |
| 强调色悬停 | `#C6613F` | `#EBA085` |
| 引用高亮底色 | `#F5E4DC` | `#4A3830` |

- **字体**:标题使用衬线字体(`"Tiempos Headline", "Source Serif 4", Georgia, serif`),正文使用无衬线(`system-ui, "Inter", sans-serif`),代码使用等宽(`"JetBrains Mono", ui-monospace, monospace`)。开源项目不得内嵌商业字体,实际加载 Source Serif 4 与 Inter。
- **圆角**:卡片 12px,按钮与输入框 10px,标签 999px。
- **阴影**:仅用 `0 1px 2px rgba(31,30,29,0.06)`,悬浮层可加到 `0 8px 24px rgba(31,30,29,0.08)`。
- **间距**:以 4px 为基数,面板内边距 16 到 24px。
- **动效**:200 到 300ms,`ease-out`,只做淡入和轻微位移;图展开动画沿用前端设计文档中的约 300ms 位置插值。

## 组件约定
- **输入框(首页仓库地址)**:居中大输入框,圆角 16px,陶土橙提交按钮,标题用衬线字体,副标题用次要文字色。
- **对话区**:用户消息为浅色气泡,AI 回答不加气泡、直接铺在背景上,引用以内联小标签显示 `文件名:行号`,点击后在图上高亮。
- **图节点**:目录、模块、文件用同一套暖色中性色阶区分,选中和问答命中用陶土橙描边与引用高亮底色;不使用彩虹配色。
- **状态提示**:「正在思考…」使用次要文字色和缓慢的三点呼吸动画。

## 合规说明
这是对 Claude 视觉风格(暖色调、衬线标题、陶土橙强调色)的**风格借鉴**,不使用 Anthropic 或 Claude 的商标、Logo 与专有字体,界面中也不得出现「Claude」品牌标识,避免被误认为官方产品。
